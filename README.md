# wechat-draft-push

通过微信公众号官方 `draft/add` 接口，将本地文章（Markdown / Word / Excel / CSV / HTML）一键推送进公众号**草稿箱**，完整保留内联样式（表格、清单、配色），并支持**按文章内容自动生成风格匹配的极简封面**。

> 这是一个 [WorkBuddy](https://www.workbuddy.cn) 用户级技能（Skill）。核心推送脚本 `scripts/wechat_push_draft.py` 为纯 Python 标准库实现，也可脱离 WorkBuddy 独立运行。

## 功能特性

- **多格式自动转换**：`.md` / `.docx` / `.xlsx` / `.csv` / `.html` → 微信内联样式 HTML（零第三方依赖，纯标准库）
- **样式完整保留**：正文提取 `<body>` 片段，内联 CSS 不丢失（告别 Markdown 工具把红/蓝色块洗掉）
- **封面自动生成**：缺封面图时，AI 代理读取文章主题，调 ImageGen 生成风格匹配、极简美观的封面（价值投资 / 科技 / 美食 / 旅行 … 各有隐喻）
- **永久素材**：封面与图片列表均上传为永久素材，草稿接口 100% 接受
- **图片列表模式**：给一组图即可拼成图文草稿

## 支持的源格式

| 格式 | 转换能力 | 当前限制 |
|------|----------|----------|
| `.md` | 标题、加粗/斜体、列表（含多级嵌套）、表格、引用、代码块 | 无已知限制 |
| `.docx` | 段落、标题样式、加粗/斜体、表格、**内嵌图片自动提取并按文档顺序嵌入** | 无已知限制 |
| `.xlsx` | 全部工作表 → 表格，**内嵌图片自动提取并附于表格之后** | 公式以存储值呈现；图表不渲染；图片统一附于文末 |
| `.csv` | 整表 → 表格 | 宽表手机端可能横向滚动 |
| `.html` | 直接使用，提取 `<body>` | — |

## 快速开始

### 1. 准备凭证
在「公众平台 → 设置与开发 → 开发 → 基本配置」获取 **AppID** 与 **AppSecret**，并把调用方公网 IP 加入 **IP 白名单**（未加白名单会报 `40164`）。

### 2. 写配置
```bash
cp scripts/wechat_config.example.json scripts/wechat_config.json
```

```json
{
  "appid": "你的公众号AppID",
  "appsecret": "你的公众号AppSecret",
  "source_file": "article.md",
  "cover_image": "cover.png",
  "cover_size": "900x383",
  "cover_prompt": "",
  "title": "文章标题",
  "author": "作者名",
  "digest": "摘要"
}
```

> `cover_prompt` 留空 `""` 即按文章内容自动匹配封面风格；填了具体描述则优先用你的。

### 3. 运行
```bash
python scripts/wechat_push_draft.py
```
脚本会：取 token → 上传封面（永久素材）→ 转换源文件 → 调 `draft/add` 推送 → 返回草稿 `media_id`。

去公众平台「内容与互动 → 草稿箱」查看即可。

## 封面风格自动匹配

缺封面时，代理读取 `title` / `digest` / `source_file` 推断主题，按隐喻生成极简封面（统一约束：极简克制、大量留白、无水印无文字）：

| 主题 | 隐喻 | 配色 |
|------|------|------|
| 财经 / 价值投资 | 护城河环绕城堡 | 深墨绿→墨黑 + 金光 |
| 科技 / AI | 发光网格 | 深蓝→墨黑 + 青光 |
| 美食 / 餐饮 | 极简食材线条 | 暖米→焦糖 |
| 旅行 / 风景 | 远山剪影 | 天青→暖白 |
| 历史 / 文化 | 水墨笔触 | 宣纸米白→淡墨 |
| 通用 / 未识别 | 抽象几何 | 深蓝→墨黑 + 金线 |

## 关键坑

- **封面必须是永久素材**：`thumb_media_id` 只接受 `material/add_material` 返回的永久 media_id；用临时素材 `media/upload` 会报 `40007`。
- **正文取 `<body>` 片段**：微信 content 接受 HTML 片段，保留内联 style 即可完整保样式。
- **IP 白名单**：未加白名单会返回 `40164`，需把调用方出口 IP 加入白名单。

## 安全

- `wechat_config.json` 含敏感凭证，**已加入 `.gitignore`，切勿提交**。
- AppSecret 使用后建议在公众平台重置，避免泄露。
- 仅操作用户自有公众号。
